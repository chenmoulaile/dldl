# dldl — 老网游单机本地化项目

> 目标:把一款十多年前的联网 Android 游戏(服务器已关停)改造成单机离线版:
> 本地伪造登录响应包 → 进游戏 → 伪造在线玩家假象 → 外挂菜单 + 内购本地化 → 重编译签名交付

## 目录约定
- `work/` — 代码修改与 git 跟踪(本仓库)
- `dist/` — 重编译产物(apk)
- `tmp/` — 临时文件(不跟踪)
